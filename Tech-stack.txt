1. Project Identity
Product Name: FixMyCity

Vision: A glassmorphic, AI-powered civic utility for high-integrity infrastructure reporting.

Core Feature: Real-time image verification using Hugging Face Transformers to filter out non-civic or fraudulent reports.

2. Fixed Tech Stack (The "Modern Web" Tier)
To ensure the best balance of 2026 performance and glassmorphic rendering, the following stack is mandatory:

A. Frontend (The UI Layer)
Framework: Next.js 15+ (App Router)

Language: TypeScript (Strict Mode)

Styling: Tailwind CSS + Radix UI (For accessible, unstyled primitives)

Animation: Framer Motion (For the glassmorphism glows and AI-scanning effects)

B. Backend & Data (The Logic Layer)
Runtime: Node.js with Hono.js (Edge-ready, high-performance API)

Database: PostgreSQL (Managed via Supabase)

GIS Extension: PostGIS (For radius-based searching and hotspot clustering)

Authentication: Clerk Auth (Supports rapid citizen onboarding via social/phone)

C. AI & Infrastructure (The Intelligence Layer)
AI Engine: Hugging Face Inference API

Primary Model: google/vit-base-patch16-224 (Vision Transformer for image classification)

Object Storage: Cloudinary (For hosting and auto-optimizing user-uploaded media)

Hosting: Vercel (Frontend/Edge) + Supabase (Backend/DB)

3. System Architecture
3.1 Data Flow
Citizen Client: Captures image and GPS coordinates.

Edge Function: Next.js Server Action sends image buffer to Hugging Face.

Validation: AI returns a label (e.g., pothole: 0.98). If the score is below 0.7 or labeled person/spam, the report is rejected before entering the DB.

Persistence: Verified data is stored in PostgreSQL.

Real-time Update: Supabase Realtime pushes the new marker to the Admin Map without a page refresh.

4. UI/UX Design System (The Glass-Dark Theme)
The design must adhere to the Glassmorphic standard:

Global Background: Deep Charcoal (#0A0A0C) with blurred mesh gradients in the background (Indigo/Teal).

Glass Cards:

background: rgba(255, 255, 255, 0.03)

backdrop-filter: blur(12px)

border: 1px solid rgba(255, 255, 255, 0.1)

Key Interaction: When the AI is "Thinking," the card border should cycle through a Neon Cyan pulse.

5. API Definition (Core Endpoint)
POST /api/report/submit
Payload:

TypeScript
{
  image: File;          // Multi-part form data
  latitude: number;     // GPS Decimals
  longitude: number;    // GPS Decimals
  description: string;  // Max 280 chars
  category: string;     // Auto-filled by AI
}
Response Logic:

200 OK: Report verified and pinned.

403 Forbidden: AI flagged image as irrelevant/fraudulent.

6. Project Roadmap (MVP)
Phase 1: Setup Next.js + Supabase + PostGIS schema.

Phase 2: Integrate Hugging Face Vision Transformer API for basic classification.

Phase 3: Develop the "Glass HUD" Dashboard for Municipal Admins.

Phase 4: Deploy to Vercel and test with real-world location data.
